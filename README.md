# Spotify-inspired Music Player Clone

## Features
- Artist, album, radio and playlist discovery pages.
- Full-screen now-playing view with animated artwork.
- Persistent bottom player with play/pause, previous, next, seeking and volume.
- Shuffle, repeat (off/all/one), queue display and keyboard shortcuts (Space, ←, →).
- Import and play MP3, M4A, OGG, WAV and other browser-supported audio files from your device.

## Audio and copyright
The project does not include copyrighted commercial Spotify recordings. Track names and artist data are demo content. To hear the actual songs, use **+ Add songs** to select audio files you own or are licensed to use.

## Run
1. Extract the ZIP.
2. Open `Spotify-clone-main` in VS Code.
3. Open `index.html` with Live Server.
4. Click a track to open the now-playing view, or choose **+ Add songs** to load local audio.

This is a static front-end project; no database, API key or payment method is required.
